# PARAÍSO Radio

Custom listener web app for a future AzuraCast-powered internet radio station.

## Current state

- Responsive listener interface
- Demo mode
- AutoDJ / Live DJ indicator
- Listener count
- Track history
- AzuraCast Now Playing API support

## Connect AzuraCast

Edit `config.js` and set `demoMode` to `false`, then add the AzuraCast base URL and station shortcode.
